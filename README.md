# Лабораторна робота №1. Фронтенд
## Варіант №7
**Тема:** Сервіс реєстрації на факультатив/подію
**Ключова сутність:** Подія (Events)
## Функціонал
* Додавання нових реєстрацій
* Відображення списку реєстрацій у таблиці
* Можливість зміни та видалення
* Пошук реєстрацій за назвою події
* Сортування за датою
* Збереження даних
## Запуск
**Python:**
python -m http.server 8080
